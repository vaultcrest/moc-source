Getting Started

Open the extension

Click the toolbar icon to open a page with your saved carts and Wanted Lists.

First-time setup

Click the gear icon to set your basic settings — PAB region (18 locales) and store location filter.

More detail on every setting is in the Settings section below.

Saving Lists & Carts to MOC Source

At the top of Pick a Brick carts, Wanted Lists, and store pages you'll find a button to save that page to MOC Source for reference.

Save Wanted List

Wanted lists can be reimported into a new list, or added to an existing one.

Save Pick a Brick Cart

Carts can be used to add parts back to Pick a Brick, or saved to a Wanted List.

Save Store Cart

Your BrickLink store cart. Store carts can be updated in MOC Source if the cart changes.

The Flagship Feature

Projects

Projects are where Wanted Lists, BrickLink carts, and Pick a Brick prices work together — planning a MOC build across multiple sources, and finding the cheapest way to fill it.

Setup

Link the wanted lists, BrickLink store carts, a Pick a Brick cart, and a scratch list you want to use for a particular project. Create multiple Pick a Brick carts to separate Bestseller from Standard, or to split across multiple carts if you go over 200 elements per type or 999 in quantity on a single lot.

Pool

The aggregated view of all unallocated parts in a project, with tabs and over-allocation highlighting. Expand it to show parts that are already allocated.

Allocating parts

Select parts with the checkboxes and use the buttons to move them between the pool, Pick a Brick, BrickLink stores, or scratch space — if you want to be opinionated about where things go.

⚡ Auto Allocate

One click assigns every pool part to its cheapest source, with a domestic-PAB-only option. We recommend starting here. If a store isn't giving you much of a discount over Pick a Brick, remove it from the project configuration — its parts return to the pool — then run Auto Allocate again for a better mix.

Scratch space

Holds parts with zero allocation — useful for stashing parts you're still hunting for a good store on, or saving for later.

Saving

Pick a Brick cart diff+replace, scratch space save, pool save, and BrickLink cart writeback ("Save Cart ↓" / "Update cart from MOC Source"). Each cart saves to its respective list and removes parts that are allocated elsewhere.

Grand total bar

Per-cart subtotals plus estimated shipping, rolled into a total cost of buying the parts — and how much you saved versus Pick a Brick by using BrickLink stores.

BrickLink Store Shop Page

Fill Wanted Qtys

  • Fills the quantity for everything on the page in the amounts your wanted list needs, so you can add it all to cart in one pass
  • Respects your New/Used condition preference from Settings when both are available
  • Read item descriptions before buying — some lots have notes about damage
  • Useful for overloading a cart with options, so you can compare prices across stores you've chosen
  • Cycle through Fill and Add to add as many wanted-list items as possible into a store's cart
  • Prune the result and use it in a Project to see which stores actually have the best price across everything you've added

Configure

Settings

  • PAB price region — determines availability and prices shown across the extension
  • Buy page store filter — auto-check "lots over max price" and "lots below wanted qty," and set your store location to buy from. On some large wanted lists the store location filter can load too early; we're working on a fix for that.
  • Wanted list page size — defaults to 10,000 to eliminate pagination in 99% of cases
  • Store Shop — Fill Button — condition preference (New/Used) for Fill Wanted Qtys
  • Project Jigsaw — LEGO fees — ignore shipping/service-fee estimates in a project's cost summary, useful when you're padding an order to hit a threshold or combining it with other orders

Before You Go

Tips & FAQ

Try overloading a cart with more lots than you need — it takes a bit longer to prune, but tends to land on the best overall mix.
Part assemblies aren't taken into account. If a wanted list wants a "Bicycle," MOC Source won't automatically recognize the individual wheels and frame it's made of.
