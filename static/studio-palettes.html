Get Started

How to use

  1. Download the zip for your region below.
  2. Extract the 5 files it contains.
  3. Copy them into this folder:
    %LOCALAPPDATA%\Stud.io\Buckets\Folders
  4. Restart Stud.io — the palettes appear in the palette picker as Pick a Brick Bestseller, Standard, Out of Stock, All, and All In Stock.

Each palette lists real Pick a Brick part/color combinations, with LDraw part files and colors resolved via MOC Source's own catalog data.
